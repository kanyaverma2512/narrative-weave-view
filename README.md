# Remix*6 of Nexus Insights

Use this version, with just enough context for Lovable to understand the product, without feeding it a 4-page manifesto:

Build the NEXUS social intelligence platform frontend directly from the attached reference image. Do not generate options or ask for approval, just execute.

Context: NEXUS analyses social-media activity across X, Telegram and other platforms to help analysts understand what narratives are emerging, how sentiment is changing, who is influencing them, how they spread across communities/platforms, and whether unusual coordinated activity is occurring.

Build these functional frontend views:

Overview: live narrative/risk summary and emerging activity

Social Feed: posts grouped by platform with sentiment/risk context

Narrative Network: users, communities, influencers and bridge nodes

Timeline: narrative growth and propagation over time

Sentiment & Emotion: how public emotion changes around a narrative

Geographic Activity: aggregate location-based activity

Platform Analytics: cross-platform distribution and spillover

Alerts: explainable warnings with the signals behind them

Narrative Investigation + Replay: select a narrative and visually replay how it emerged and spread

Use realistic mock data for now, structured for easy backend API integration later. Keep the attached premium light aesthetic: pastel pink/peach/lavender/mint/blue, subtle gradients, glass effects, refined shadows and clean typography. Add tasteful 3D depth to graphs/charts where useful. No neon, cyberpunk or clutter.

Frontend only. Do not change/build the backend.
